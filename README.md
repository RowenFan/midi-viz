# 钢琴直播光柱特效 midi-viz

弹琴时，琴键上方会实时升起发光的光柱。这些光柱叠加在摄像头拍到的真钢琴上，用 OBS 推流到抖音、B 站、YouTube 都可以。

- 实时接收 MIDI 键盘的信号，按下就出光柱，延音踏板也会显示
- 3 种光柱样式：发光方块、胶囊、细光丝
- 13 种配色，7 种上色方式：跟着和声变色、按音高、按力度、左右手分色等
- 可以显示和弦名、调性、五线谱、BPM 和力度信息栏，还能加自定义字幕和署名
- 用四个角点把特效对准画面里的真琴键，镜头歪着拍也能对上

## 需要什么

- 一台电脑，装好 Chrome 和 [OBS](https://obsproject.com/)
- Python 3，只用它来开一个本地网页服务
- 一个 MIDI 键盘或者电钢琴，用 USB 连到电脑
- 一个对着琴键拍的摄像头，手机当摄像头也可以

## 怎么用

### 1. 启动本地服务

在这个文件夹里运行：

```bash
python3 -m http.server 5178
```

### 2. 打开特效窗口

在 Chrome 里打开下面这个地址。第一次会请求 MIDI 权限，点允许。

```
http://localhost:5178/?live=1&overlay=1
```

如果用的是 macOS，也可以直接运行 `./open-overlay.sh`。它会开一个单独的、没有地址栏的 Chrome 窗口，方便 OBS 采集。

### 3. 在 OBS 里采集这个窗口

1. 在 OBS 里新建一个「窗口采集」源，选中这个 Chrome 窗口。
2. 把它放在摄像头源的上面。
3. 右键这个源，选「混合方式」→「滤色 Screen」。黑色背景就会变成透明，只剩下光柱。
4. 把它拉伸到和摄像头画面一样大。

### 4. 标定：把光柱对准真琴键

第一次打开会自动进入标定。之后想再调，在窗口里按 **C**。

1. 截一张摄像头画面，直接拖进窗口里当底图，对着它标会比较准。
2. 把四个角点分别拖到琴键的四个角上。左边对准最低的那个键，右边对准最高的那个键。
3. 拖好后按 **C** 收起。

小技巧：

- 选中角点后，用方向键可以微调。按住 Shift 一次挪 10 像素，按 Tab 切换到下一个角点。
- 如果不是 88 键的琴，在地址后面加上 `&lo=` 和 `&hi=`，分别填最低音和最高音的 MIDI 编号。比如 61 键就加 `&lo=36&hi=96`。

### 5. 调样式

在窗口里按 **P** 打开设置面板，光柱样式、配色、亮度、字幕、署名都在这里改。改完会自动保存。

## 没有 MIDI 键盘也能试

- 用电脑键盘弹：A S D F G H J K 是白键，从中央 C 开始；W E T Y U 是黑键；空格是踏板。
- 地址里不加 `live=1`，直接打开 `http://localhost:5178/`，会播放一段内置的德彪西《月光》作为演示。
